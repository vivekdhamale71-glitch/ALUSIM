# 2310214L.CO4 — Solve given problems using searching and sorting techniques  [L3]

**Files:** `Sorting.h` (Bubble, Insertion, Quick + generic `quickSort<T>`), `Searching.h` (Linear, Binary, Fibonacci + generic `binarySearch<T>`).

**Problems solved:**
- the lexer finds keywords (`if`, `for`, `while` …) by **binary search** in a sorted keyword table
- the opcode table is **quick-sorted** at start-up and every mnemonic is **binary-searched** by the assembler
- the Data Lab **sorts** the profiler's instruction counts and **searches** data memory, comparing the steps of each method

**See it in the app:** Compiler → keyword lookup · Assembly mode → opcode lookup · Data Lab → Sorting / Searching.
