# PL — Programming Lab - Data Structures · 2310214L

Data structures written in C++, each used by the simulator itself. Most are templates: the `.h` declares the class and the matching `.cpp` defines every member function. Because a template must be visible wherever it is used, the header includes its `.cpp` at the end (the `.cpp` has an include guard). Ordinary classes (sorters, searchers, hash tables) are normal `.h` / `.cpp` pairs.
