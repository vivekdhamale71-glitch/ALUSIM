# 2310214L.CO5 — Apply suitable hashing techniques for solving given problems  [L3]

**Files:**
- `HashTable.h` — abstract `HashTable` with **Linear probing**, **Quadratic probing** and **Separate chaining**; records every probe, collision and rehash
- `HashMap.h` — generic `HashMap<K,V>` (chaining, FNV-1a / multiplicative hashing)

**Problems solved:** variable symbol table and label table (method chosen by the user), opcode dispatch,
register-name lookup, sparse memory, micro-code dispatch ROM, translation cache.

**See it in the app:** Compiler → symbol table card (Linear / Quadratic / Chaining) · Data Lab → Hashing.
