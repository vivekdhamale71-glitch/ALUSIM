# COA — Computer Organization & Architecture Lab · 2310221L

A complete virtual x86-64 processor (80386 lineage) written in C++.

| CO | Folder | Statement |
|---|---|---|
| 2310221L.CO1 | `CO1_Architecture/` | Explicate the architecture and instruction set of the 80386 microprocessor. |
| 2310221L.CO2 | `CO2_AssemblyISA/` | Develop assembly language programs using 80386 instruction set. |
| 2310221L.CO3 | `CO3_ComputerArithmetic/` | Illustrate processor level details about arithmetic operations using computer arithmetic algorithms. |
| 2310221L.CO4 | `CO4_ControlUnitPipeline/` | Demonstrate the different ways to generate control signals and their organization techniques and instruction pipelining of computer system. |
