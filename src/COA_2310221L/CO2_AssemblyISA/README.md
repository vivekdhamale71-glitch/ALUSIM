# 2310221L.CO2 — Develop assembly language programs using 80386 instruction set.

Programs written in assembly (or generated by the compiler) are assembled by a two-pass assembler and run on the simulated CPU. The instruction semantics that depend on processor details are themselves assembly: branch conditions use the real SETcc, IDIV the real IDIV, CQO the real CQO.

## Where you see it in the simulator

- Compiler screen in Assembly mode: write x86-64 directly; errors point at the line.
- Every Jcc, IDIV and CQO executed by a program calls into isa.asm.
