# 2310261L.CO1 — Real-world problems with OOP  [L3]

**Files:** `English.h / .cpp` — `EnglishTranslator`: turns plain English ("add 12 and 3",
"if marks is at least 40 then …", "find the factorial of 5") into code. A real-world problem —
letting a person describe a computation in their own words — solved with a recursive-descent parser class.

**See it in the app:** Compiler → English mode → "English → Code" card.
