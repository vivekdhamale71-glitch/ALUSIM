(`Instruction`, `ControlUnit`, `HashTable`, `Sorter`, `Searcher`, `View`), templates (all of `PL_2310214L`),
operator overloading (`Register64`, `Vec2`, `Mat3`, `Flags`). The folders below hold the parts written mainly for these COs.
